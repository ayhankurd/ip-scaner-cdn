# 🔍 CDN Clean IP Scanner - اسکنر گره خروجی

یک ابزار **HTML/JavaScript** برای پیدا کردن آی‌پی‌های تمیز از CDNهای مختلف. 
**بدون نیاز به نصب، فقط با یک مرورگر!**

## ✨ ویژگی‌ها

- ✅ پشتیبانی از ۴ CDN: Cloudflare, Google, Akamai, Fastly
- ✅ تست پورت‌های مختلف (۴۴۳، ۲۰۵۳، ۲۰۸۳، ۲۰۸۷، ۲۰۹۶، ۸۴۴۳)
- ✅ نمایش پینگ لحظه‌ای
- ✅ خروجی آماده برای پنل Nova
- ✅ کاملاً در مرورگر اجرا می‌شود
- ✅ بدون نیاز به نصب یا کتابخانه

## 🚀 نحوه استفاده

1. فایل `scanner.html` را دانلود کنید.
2. در مرورگر باز کنید.
3. تنظیمات را انتخاب کنید و روی "شروع اسکن" کلیک کنید.
4. نتایج را کپی کرده و در پنل خود استفاده کنید.
